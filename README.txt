GLOBETROTTER — THE LOST PASSPORT | REBORN PROTOTYPE V2.0
by BROT2YOU

Open index.html in a browser. No server, login or internet required.

New standalone playable prototype, built separately from the previous game.
Four point-and-click London scenes, clickable characters/objects, dialogue choices,
clues, unlockable Culture Arcade with 3 games and 9 questions, Pixel Passport,
autosave and export/import of save data.

All visuals reuse existing GLOBETROTTER pixel art supplied by the user.
Some exploration scene assets from the original app are low-resolution placeholders;
they will benefit from dedicated new pixel-art backgrounds in later versions.

To publish, create a NEW GitHub repository or branch first; do not overwrite
the existing Atlas-Quest app before testing.
